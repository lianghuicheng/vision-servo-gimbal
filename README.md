# 视觉伺服云台系统（Vision-Servo Gimbal）

> 电赛控制类/仪器类题目的通用骨架 ｜ 自动化专业本科生个人项目
> 时间：2026.11 – 2027.08

**一句话**：摄像头识别目标 → 自定义串口协议 → STM32 解析 → 双轴 PID 闭环 → 云台稳定跟踪。

---

## 为什么做这个

自动化专业学生的优势不是"会调 YOLO"，而是**懂被控对象、能把算法落到真实系统上**。
这个项目把「感知 — 通信 — 控制 — 电源 — 结构」五个环节串成一条链，
既是电赛控制类题目的最小可用骨架，也是求职时能讲 20 分钟的硬核项目。

---

## 系统架构

```
┌──────────────┐   USB/UART     ┌──────────────┐   PWM    ┌────────┐
│  视觉端       │  ───────────►  │   主控        │ ───────► │ 云台舵机│
│ (PC / K210/  │   自定义帧协议  │  (STM32F103) │          │  2 轴   │
│  K230)       │  ◄───────────  │              │          └────────┘
│              │   状态帧(v2)    │   PID 闭环    │
│ OpenCV 识别   │                │   安全兜底    │
│ 打包坐标      │                │              │
└──────────────┘                └──────────────┘
       │                               │
       └──── 各自独立供电，仅共地 ──────┘
```

| 模块 | 目录 | 技术栈 |
|---|---|---|
| 视觉端 | `02_vision_host/` | Python 3.14 + OpenCV 5.0 + pyserial |
| 主控固件 | `01_firmware_STM32/` | STM32F103 + HAL + DMA/IDLE + 定时器 PWM |
| 协议规范 | `03_协议文档/` | 自定义帧：帧头 + 长度 + PAYLOAD + CRC16 + 帧尾 |
| 测试记录 | `04_测试记录/` | 延迟、成功率、长稳测试数据 |
| 演示素材 | `05_演示素材/` | 视频、GIF、接线图、实物照片 |

## 快速开始

### 1. 环境准备

```powershell
# 依赖（本项目只需这几个）
python -m pip install pyserial opencv-python numpy
```

### 2. 验证串口通路（W1）

```powershell
cd 02_vision_host
python serial_hello.py --list        # 列出串口
python serial_hello.py --port COM5   # 发消息，用 XCOM 看
```

### 3. 先测协议，不接摄像头（W3）

```powershell
python protocol.py                   # 自测：CRC 向量 + 粘包/断包/错帧
python vision_send_demo.py --mode sweep          # 发送正弦扫动的假目标
python vision_send_demo.py --mode sweep --dry-run  # 只打印，不发串口
```

### 4. 接摄像头（W2 起）

```powershell
python vision_send_demo.py --mode camera --port COM5
```

## 协议速览

```
AA 55 | LEN | PAYLOAD | CRC16(小端) | 0D 0A
```

| type | 名称 | 说明 |
|---|---|---|
| `0x01` | TARGET | cx, cy, w, h (uint16) + angle (int16, 0.1°) |
| `0x02` | LOST | 目标丢失，字段全 0 |
| `0x03` | HEARTBEAT | 心跳，每 500 ms |

完整规范与联调清单见 [`03_协议文档/串口协议_v1.md`](03_协议文档/串口协议_v1.md)。

## 关键设计决策（面试会问）

| 决策 | 原因 |
|---|---|
| 为什么自定义协议而不用 ASCII？ | 二进制帧更省带宽、解析更快、CRC 可靠；ASCII 在 30 fps 下要浪费一倍带宽 |
| 为什么用 IDLE + DMA 收？ | 轮询会阻塞主循环，PID 周期抖动就永远调不好 |
| 为什么 PID 用固定周期定时器？ | 采样周期不定 → 积分/微分项失真 → 参数无意义 |
| 为什么舵机独立供电？ | 舵机堵转电流可达 2 A，共电源会把 MCU 电压拉崩导致复位 |
| 为什么发 LOST 帧而不是不发？ | 主控要能区分"没有目标"和"视觉端死了"，前者继续搜索，后者要安全停车 |
